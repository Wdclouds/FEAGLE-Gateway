# FEAGLE Hub · AI Agent 多群治理中台与桌面控制中心

> **FEAGLE 双子星架构核心组件**：专注于微信生态的多群 Prompt 编排、工具权限管控、全双工实时消息流转与遥测大盘。  
> 追求**极致轻量、零臃肿 Electron 依赖、开箱即用、免隧道直连**。

---

## 🌟 核心特性

- 🦅 **双子星解耦架构**：底层由 `FEAGLE-Gateway`（Android LSPosed Hook + Bridge 驱动）负责纯物理发信与 OneBot v11 转译；上层由 `FEAGLE-Hub` 全权负责 AI 决策、多群人设治理与可视化桌面大盘。
- ⚡ **免隧道云端直连 (Bridge Sync)**：告别任何繁琐的 SSH 隧道打洞！在界面直接输入你的服务器公网 IP（如 `http://your-server-ip:6190`），Hub 自动通过 HTTP REST & SSE 实时流同步云端微信在线状态、设备健康度与真实对话流。
- 🔌 **全双工双模网关支持**：
  - **云端直连模式 (`bridge_sync`)**：推荐模式，直接拉取并同步远程服务器上的 Bridge。
  - **本地监听模式 (`server`)**：本地开启 OneBot v11 反向 WebSocket 服务端（默认 `:6199`），等待本地 Bridge 或反向代理连入。
  - **远程客户端模式 (`client`)**：作为 OneBot 客户端主动连接指定 WebSocket 服务端。
- 🎯 **多群 AI 策略矩阵**：支持针对不同的微信群，独立配置专属的 **System Prompt（人设）**、**AI 工具白名单（哪些群能调用搜索，哪些群能执行代码/终端）**、**触发响应模式（智能回复 / 仅@触发 / 静默观察）**。
- 🛡️ **原生轻量 SQLite WAL 引擎**：基于 Node.js 22+ 内置的标准库 `node:sqlite`（零 C++ 编译风险、零笨重 ORM），高并发读写，自动记录每一次策略更新的操作人与审计日志。
- 💻 **轻量原生桌面窗口封装**：内置基于 Windows Edge 应用模式（`--app`）的一键启动器，无浏览器地址栏、无多余边框、独立窗口图标，启动秒开且内存占用极低。

## 🚀 3 分钟极速上手

### 1. 安装环境与依赖
确保系统安装了 **Node.js 22.0.0+**（内置 `node:sqlite` 与原生 WebSocket 支持）。

```bash
cd apps/hub
npm install
```

### 2. 启动服务
```bash
npm start
```
服务将在后台启动并监听本地端口：
- **Web 控制中台**：`http://127.0.0.1:6200`
- **反向 WS 服务端**：`ws://0.0.0.0:6199/ws`

> **Windows 桌面用户**：可以直接双击运行项目根目录下的 **`FEAGLE Hub.bat`**，将自动拉起独立原生桌面窗口！

### 3. 登录与连接网关
1. 打开浏览器访问 `http://127.0.0.1:6200`；
2. 输入默认管理员账号登录：
   - **用户名**：`admin`
   - **密码**：`admin123`
3. 登录后，在顶部或网关卡片点击 **【⚙️ 配置】**：
   - **连接云端微信**：选择 `云端直连模式`，输入你的服务器 IP（例如 `http://39.97.255.91:6190`），点击保存即可秒级连通云端微信！
   - **本地调试**：选择 `本地监听模式`，保持默认端口 `6199` 即可。

## 🎛️ 多群 AI 策略编排指南

进入左侧导航栏的 **「多群策略编排 (/groups)」**：
1. **自动同步群聊**：在直连模式下，云端 Bridge 已经捕获的微信群组会自动纳管出现在群列表中；
2. **编排独立策略**：点击任意群的 **【编排策略】**，可以自由配置：
   - **人设 Prompt**：为技术交流群设定“硬核代码助手”，为水友群设定“机敏幽默助理”；
   - **授权 AI 工具**：勾选允许该群调用的工具（如 `web_search` 联网搜索、`terminal` 终端执行等）；
   - **响应模式**：
     - `SMART`（🟢 智能回复）：自动判断语义智能应答；
     - `MENTION_ONLY`（🟡 仅@回复）：必须有人 `@小号` 才触发回复；
     - `OBSERVE`（⚪ 静默观察）：只收录消息与分析，不发信打扰群友。
3. **策略热下发**：保存后策略立即生效并持久化，操作审计日志自动归档。
