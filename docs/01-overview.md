## 1. 行业痛点与传统方案死穴

在微信生态中构建高可用、拟人化、可执行工程任务的 AI 自动化机器人，长期以来面临三大死穴：

### 1.1 封号高危与协议脆弱性
* **Web 网页版协议（如 wechat4u、Puppeteer）**：微信官方在过去数年中逐步全面收紧了网页版扫码登录权限，绝大多数微信新老账号均被禁止登录 Web 端。
* **逆向 iPad/Mac 私有协议**：通过二进制逆向破解的私有协议极易被微信安全风控系统的行为指纹检测（如 TLS 指纹、设备心跳异常、发信频率无随机波动），导致账号被秒封或频繁弹出人脸识别校验。
* **PC 注入式 Hook**：Windows 端微信更新频繁，内存偏移量频繁变动极易导致崩溃，且容易被系统安全策略查杀。

### 1.2 会话混乱与模型额度黑洞
* **单体无状态或全局会话共享**：绝大多数开源项目将所有群聊的消息一股脑塞入同一个会话上下文中，导致“群 A 的问题在群 B 被回答”、“张三问话李四接着聊”的严重串话现象。
* **缺乏任务熔断与额度保护**：社群中经常出现恶作剧群友发送长篇论文、恶意提示词或超长工程任务（如“帮我写一个完整商城系统”）。传统单体机器人直接将任务发往高成本模型，一次调用可能烧尽数十万 Token 甚至锁死整个实例。

### 1.3 权限失控与缺乏可视化治理
* 无法针对不同群聊精确授权能力（例如：技术群允许执行代码工具，普通售后群仅允许闲聊与备忘）。
* 缺乏统一、现代化的管理后台，难以直观掌握真机连接质量、消息吞吐统计与群成员画像。

## 2. FEAGLE WxBot 核心设计哲学

针对上述死穴，FEAGLE WxBot 确立了五项不可逾越的底层设计原则：

### 原则一：物理硬件级安全隔离 (Hardware-Level Physical Isolation)
* 坚决摒弃任何虚拟化逆向协议与 Web 网页协议。
* 选用真实的三星平板硬件（Samsung Galaxy Tab A8, SM-X200），搭载官方原生 Android 14 系统。
* 运行官方 64 位微信客户端（v8.0.78），通过系统级 Magisk + Zygisk + LSPosed 模块进行底层事件监听与模拟注入。在微信安全风控感知维度，一切操作均发生在一台真实、合法的移动设备中。

### 原则二：四层漏斗逐步分流 (Funneling Pipeline)
* 消息绝非无脑调用大模型。
* 严格遵循 `L0 规则层 -> L1 语义路由层 -> L2 工程执行层 -> L3 出站防风控层` 的流水线分流机制。
* 越靠前的层级耗费越低：
  - **L0**：纯本地 TypeScript 代码，0 延迟、0 Token 成本，秒级收敛硬指令、黑名单与越狱攻击；
  - **L1**：采用高并发极速模型（Gemini 3.8 Flash），负责意图判决、闲聊秒回与巨型任务额度熔断；
  - **L2**：受保护的单例进程，仅在明确工程任务时受租约唤醒；
  - **L3**：微信原生引用回复切片与拟人化随机等待防风控。

### 原则三：物理级社群沙箱 (Per-Chat Physical Sandbox)
* 每个群聊在网关数据目录下分配唯一的物理目录（`data/channels/<chatId>/`）。
* 沙箱内人设 Prompt、安全红线守则、工具白名单、群成员画像与会话备忘录全部物理级隔离，互不干扰、互不越权。

### 原则四：带权属的技能热拔插与零残留注销 (Zero-Orphan Skill Lifecycle)
* 无论是内置的生图工具，还是未来引入的外部 GitHub Skill 扩展包，其面向用户的硬指令（如 `/draw`）必须附带 `skillId` 权属绑定。
* 当关闭或卸载该能力时，系统通过原子级级联清理彻底从内存指令字典与工具注册表中注销，绝不在源头上留下任何孤儿逻辑或闭包隐患。

### 原则五：单端口极简接入与现代化控制台
* 前端采用 Vue 3.5 + TypeScript 5.6 严格模式构建，支持赛博毛玻璃拟态与 OLED 纯黑夜间模式。
* 后端通过原生流式反向代理将网关、桥接与静态页面统一收敛在单个端口（`:6190`），实现零配置免跨域访问。

## 3. 方案对比矩阵

| 评估维度 | 传统 Web 协议 (Wechaty/Puppeteer) | 逆向 iPad/Mac 协议 | **FEAGLE WxBot (本系统)** |
|---|---|---|---|
| **封号风险** | 极高（账号已被微信全面屏蔽） | 极高（行为特征检测与封禁） | **极低（官方平板真实微信客户端）** |
| **消息类型支持** | 仅文本、极易丢图 | 文本、图片（协议常失效） | **文本、原生高清图、wxgf视频、引用回复** |
| **会话隔离机制** | 全局混杂，内存易泄露 | 简单 Map 映射 | **物理级沙箱目录 + 15分钟衰减环** |
| **大模型集成** | 简单 Prompt 拼接 | 简单单轮问答 | **四层漏斗 + Gemini 3.8 + Imagen 生图闭环** |
| **工程执行力** | 无执行能力 | 需外部挂载脚本 | **受租约保护的单例 Pi 引擎 (Shell/Git)** |
| **运维体验** | 纯命令行终端输出 | 简陋控制面板 | **Vue 3 现代化毛玻璃控制台 + 单端口反代** |
