# 06 - Web 统一管理控制台规格

> **版本**：v5.1 (Production Baseline)  
> **模块**：FEAGLE WxBot 前端与人机交互篇  
> **基准代码**：`apps/web` (Vue 3.5 + Vite 6 + TS 5.6) · `apps/bridge/src/dashboard.js`  

---

## 1. 前端工程架构与技术栈

FEAGLE Web 控制台是一套面向生产环境的单页治理后台，彻底重构并替代了旧版的无类型纯 JS 页面。

### 1.1 技术选型与技术栈版本
* **构建底座**：Vite 6 + Vue 3.5 (Composition API `<script setup>`)；
* **强类型系统**：TypeScript 5.6 (配置 `strict: true` 严格模式，全工程零隐式 `any`)；
* **状态中枢**：Pinia 2.2；
* **路由导航**：Vue Router 4.4 (`createWebHashHistory`，消除刷新 404)；
* **原子化样式**：Tailwind CSS 3.4；
* **图标体系**：Lucide Vue Next 图标库；
* **数字工业字体**：引入 `DSEG7 Classic` 工业七段数码管字体呈现跳动时钟。

---

## 2. 视觉设计系统与主题规范

### 2.1 赛博毛玻璃拟态与 OLED 纯黑夜间模式
控制台默认提供**深色赛博毛玻璃拟态（Cyberpunk Dark Glassmorphism）**与工业级白天模式的一键无缝平滑切换：
* **OLED 纯黑极致护眼**：夜间模式主体底色采用纯黑（`#000000` 与 `#080808`），配合 `border-white/[0.08]` 极细微半透明边界，彻底消除传统暗色界面的灰蒙泛白感；
* **呼吸光晕与健康指示灯**：针对微信在线状态、心跳延迟、服务健康度，提供带有 CSS 脉冲动画的荧光绿/琥珀黄/警报红状态呼吸灯。

### 3.1 视图 1：系统总览与节点健康 (Overview)
* **WeChat Hero 核心卡片**：展示当前绑定的微信头像光环、微信昵称、协议健康度、最近一次心跳往返延迟（RTT ms）与今日重连次数。
* **微信运行模式快速切换器**：
  - `RUNNING`（正常响应交互）；
  - `PAUSED`（临时暂停消息回复）；
  - `MANUAL_OFFLINE`（强制下线断开）。
* **4 项基础设施健康检测卡片**：
  1. **Android 物理驱动**：监听 `:6191` 平板长连接状态，显示设备型号（SM-X200）与信道活跃度；
  2. **Gateway Pi 引擎**：显示网关当前租约持有情况与常驻内存；
  3. **SQLite 审计状态**：实时展示当前全量会话数与 Traces 历史审计条数；
  4. **定时休眠时段**：当前是否处于免打扰静音时段，支持管理员一键解除限时静音。
* **7 项消息管道吞吐量遥测指标**：以数码徽章实时呈现累计**观察、转发、回复、拦截、策略、限流、熔断**的频次。

### 3.2 视图 2：社群沙箱与成员画像 (Channels)
* **沙箱卡片网格**：多维度搜索过滤（群名称、群 ID），展示真实中文群名、物理沙箱目录、成员统计、已授权工具标签。
* **沙箱抽屉编辑器**：
  - 动态拉取工具目录，一键勾选授权该群的工具白名单；
  - 实时编辑该群专用的 `persona.md`（人设提示词）与 `rules.md`（不可逾越的群规）；
  - **15 分钟衰减环动态进度条**：直观展示当前群当前多轮会话剩余衰减倒计时秒数，支持点击“重置会话”立即归档清空。
* **群成员画像与标签治理**：
  - 点击“群成员画像”打开侧滑抽屉，以现代化表格列出群内所有发言成员的发言次数、最近活跃时间；
  - 点击单成员弹出编辑模态框，配置成员的角色（`role`）、能力与偏好标签云（`tags`）、协同关注点（`notes`），保存后即刻持久化至 `members.json`。

### 3.3 视图 3：全局工具目录 (Tools)
* 呈现当前网关注册的所有工具列表，清晰标识“系统核心内置”与“自定义扩展”。
* **参数 Schema 树形可视化查看器**：解析工具的 JSON Schema 定义，格式化展现每个参数的名称、类型要求、默认值、必填标记与中文详细描述。
* **自定义 Webhook 工具动态注册**：支持管理员通过控制台在线输入工具名称、说明、参数规范与回调端点 URL，即刻热注入网关工具库。

### 3.4 视图 4：终端实时日志流 (Logs)
* 通过 SSE（Server-Sent Events）长连接直接对接 `:6190/logs` 流；
* 维持 **1000 行环形内存缓冲区**，确保长时间挂机浏览器不会爆内存崩溃；
* 提供按级别过滤（`ALL` / `INFO` / `WARN` / `ERROR` / `DEBUG`）；
* 支持全文检索高亮定位、暂停/锁定滚动屏幕、一键导出与复制最新日志。

### 3.5 视图 5：桥接设置与防风控限流 (Settings)
* **防风控频率限制**：滑动调节单用户 30 秒内最大发信数、群聊 5 秒回复冷却 CD；
* **拟人随机等待调节**：双向滑块设定出站切片随机抖动区间（如最小 800ms ~ 最大 1500ms）；
* **静默时段校验**：输入 `00:00-07:00` 格式，前端执行严格的正则表达式与时间逻辑校验。

## 4. 全局弹窗：设备扫码配对与 APK 下载向导

控制台右上角常驻“设备连接向导”入口，点击弹出全功能物理连接对话框：
1. **多网卡 IP 智能选择**：自动嗅探服务器本地多张网卡 IP（公网 IP 与局域网内网 IP），支持下拉切换；
2. **免密配对二维码**：根据所选 IP 与随机 Ticket 生成高清晰度配对二维码，平板端扫码即可完成安全凭证绑定；
3. **APK 下载通道**：
   - 提供蓝奏云极速下载二维码与配套提取码一键复制；
   - 提供服务器本地直链下载按钮（下载存放在 `public/downloads/feaglewxbot-agent.apk` 的最新安装包）。
